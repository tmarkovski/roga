Rather Opinionated Git App

A Git client for the way code gets written now.

Other Git clients were built for people clicking through Git. Today you’re more likely to be watching agents work in parallel worktrees and reviewing what they did. Roga is a native Mac app built for that.

Download for the Mac brew install --cask tmarkovski/roga/roga

Free and open source · Apache 2.0 · macOS 26 or later

Know what every agent is doing.

Every worktree gets a row in the sidebar. Install the hooks for Claude Code or Codex from Settings, and each row shows whether its agent is working, finished or waiting for your OK, with a line saying what it’s doing.

Review it like a pull request.

Roga shows everything a branch changed since it left main: its commits and one combined diff, with the changed words highlighted.

Stuck? Ask the agent you already have.

Some Git clients charge extra for AI. Roga hands the hard parts to the Claude Code or Codex you’re already signed in to: a merge conflict, a commit message, or a command Git refused. They can only answer: what they write comes back to you, and nothing is marked resolved or run until you say so.

No API keys · No AI add-on to pay for · No limits from Roga

A real Mac app.

Roga is written in Swift, with no web views standing in for the interface. It follows your Mac between light and dark, and keeps itself up to date.

Then play it back.

A hard week’s work deserves more than a merged pull request. Roga replays a branch’s history as a metro map, with a departure board counting every commit as it lands, and ends on a poster of what the team got done. Save it as a video or an image and send it to them.

  • Fast on huge repositories. Roga reads Git’s commit-graph file directly and loads only the rows on screen. Checking out a branch in the Linux kernel takes about 0.4 seconds.
  • Git stays in charge. Roga runs the Git you already have and keeps no hidden state, so you can drop to the command line at any moment.
  • Free and open source. Apache 2.0, with the code on GitHub. No account to create and nothing to pay for.
