The first beta of Roga, a fast, native Git client for the Mac, made for keeping an eye on agents and reviewing what they wrote. Roga stays in beta until 1.0.0.

Roga needs macOS 26 or later. Install it with Homebrew, or download `Roga.dmg` below and drag Roga to Applications:

```bash
brew install --cask tmarkovski/roga/roga
```

It keeps itself up to date with Sparkle.

## What's in it

- **History** for repositories of any size, read from git's commit-graph file, with a graph that runs each line down to its parent.
- **Diffs** with changed words highlighted, for one commit, two commits, a run of commits, a stash, or everything a branch changed since it left its base, the way a pull request shows it.
- **Worktrees** in a sidebar grouped by organization. Make new ones, repair one whose folder moved, and delete the ones you're done with.
- **Agents.** Settings installs hooks for Claude Code and Codex. The sidebar then marks each worktree where an agent is working, waiting for you, or finished, and says what it's doing. Either agent can write your commit message.
- **Everyday changes.** Stage files, commit and amend, discard with Undo, fetch, pull and push, start branches, check out a branch or go to a commit with a double-click, revert a commit, and delete branches. When uncommitted changes are in the way of a pull, Roga sets them aside and puts them back.
- **Live refresh.** Roga watches every worktree, so what you and your agents change shows up as it happens. Its reads in the background never take git's index lock, so they don't get in an agent's way.
