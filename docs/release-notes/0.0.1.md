A rehearsal of how Roga is released, not a release to use. Please don't install it.

It's here to check, before the first release, that a copy of Roga built, signed and notarized the way every release will be can update itself to the next one. It stays a prerelease, so no copy of Roga is ever offered it, and it goes once 0.1.0 is out.

The first release will be 0.1.0, at [roga.sh](https://roga.sh).
