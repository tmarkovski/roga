The first update to Roga 0.0.1, with colors and a code font to choose, tags you can push, and a steadier Generate popover.

## What's new

- **Colors and code font.** Settings › Appearance has Colors, with Monokai, which keeps Roga's colors so far, or Xcode's. Under it, Code font picks the family and size for diffs and conflicts. A preview of the window follows each choice as you make it.
- **Push a tag.** A tag's menu has Remote › Push to origin, in history and in the refs panel. The New Tag popover has a Push to origin checkbox, which starts unchecked every time.
- **Generate popover.** Each agent's row shows its own model and effort, and on the picked agent's row they're menus. The popover keeps its height as you switch agents, and the Generate button under it runs what's picked.
- **Add Repositories** opens at its full size right away, since finding clones no longer runs git in each one. With nothing in the sidebar, it asks for a folder first.

## Smaller changes

- Organizations in the sidebar are separated by a line with their name in the middle.
- A branch's hover buttons say what they do in their tooltips, and sit in the middle of the row.
- The Remotes header drops its count, and its plus lines up with the buttons on the rows.
- Settings, dialogs, setup and conflicts use plainer, standard wording.
- Motion is out of Settings for now, and the house plays at normal speed.
