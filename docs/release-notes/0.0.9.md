The sixth update to Roga, which shows who a repository's commits go out as, marks and checks signed commits, clones from a URL, and puts the message box's buttons in a row under its text.

## What's new

- **Who your commits go out as.** A person at the right end of the title row stands for the name and email a repository's commits will carry, as git config has them. It's gray for your global identity, and takes a color of its own when a repository commits as someone else. It turns amber with a triangle when the next commit would go wrong, as when no email is set, and gets a small shield when commits are signed. Clicking it opens a popover where you can change the name, the email and signing for this repository or for every repository, and it shows the `git config` command it will run. The message box also says who a commit goes out as whenever that isn't your global identity, and Settings › Git lists the repositories that set their own.
- **Signed commits.** History marks commits that carry a signature. The commit panel checks the selected one, and its Signature line says whether the signature is good and which key made it. When git can't vouch for a signature made with one of your own SSH keys, Trust This Key… adds the key to your allowed signers file. The Key field lists the signing keys this Mac has, including the SSH agent's and 1Password's, and New SSH Key… or New OpenPGP Key… makes one. Checking can be turned off in Settings › Git.
- **Clone from a URL.** Add Repositories has two tabs, On This Mac and From a URL. Paste a URL, choose a folder, and click Clone. The repository gets its row in the sidebar straight away, with how far git has got on a second line and Cancel clone in its menu. Submodules are cloned too, unless you turn that off. File › Clone Repository…, Shift-Command-O, goes straight to it.
- **A new message box.** Generate is at the left and Commit at the right, in a row under the text, and the heading and footer are gone. A chip at the top says when a commit isn't an ordinary one, such as Amending or First commit on main. While an agent writes, Generate turns into Stop. When a commit fails, the box shows what git or the hook printed, with Skip Hooks when a hook could be the reason.
- **What the agent is doing, in the branch row.** After the counts, the branch row shows the worktree's agent, what it's doing and for how long, as in `Run the test suite · 6 min`. Clicking it opens a popover with a section for each session. History's row for uncommitted changes shimmers while an agent works.
- **One scroll for a worktree's files.** Conflicts, Unstaged, Untracked and Staged are one list that scrolls as a whole, and each list's heading stays in view while its files scroll under it.

## Smaller changes

- History shows about 0.4 seconds sooner at launch. Roga looks for git in the `PATH` it saved last time while the login shell starts again, and opens the repository a window shows before the others.
- A sidebar row's name is faint until its files are counted, and its count and second line fade in as they arrive.
- Choosing which copy of git, Claude Code or Codex Roga runs opens a popover of cards, laid out like the agents' popover.
- Buttons are in title case everywhere.
- Settings' rows line up on their middles, and Git has four sections: Installation, Identity, Signing and Background tasks.
- A control whose only job is to open a popover, such as Add Repositories, the identity, or the chevrons on Generate, Resolve and Fix, opens it as the mouse button goes down, as Roga's menus already did.
- Settings › Appearance has an Animate the house switch. With it off, the title row shows words instead of the house, and the Fetch button pulses instead of dropping the house.
- Text that a button would cover on hover, such as a file's path beside Mark Resolved, now fades out before the button.
- The shown worktree's tab is white with a soft shadow, on a gray band that runs along the top of the window.
- A branch that has never been pushed counts its commits against the main branch on its tab, so an agent's worktree with commits waiting shows `↑3` rather than nothing.
- Commit's chevron stays dark while Commit can't be pressed but Amend can, and a repository with no commits says First commit on main rather than Detached HEAD.
- The branch's chip is as tall as the counts beside it.
