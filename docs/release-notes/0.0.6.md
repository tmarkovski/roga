The third update to Roga, with stashes you can make and put back in a click, worktrees made from the sidebar, one switch and one default agent for everything agents do, and an agent popover behind Generate, Resolve and Fix.

## What's new

- **Stash changes.** The Uncommitted Changes header has Stash Changes, and so does Changes › Stash Changes (Shift-Command-S). It stashes everything, staged and untracked files included, names the stash after its files and selects it. The title row says how many files went in, with Undo.
- **Put a stash back.** Right-clicking a stash offers Put back, Put back and keep the stash, New branch from stash…, Copy message and Delete, and a selected stash's panel has Put Back. Delete has Undo in the title row. A put back that stops on a conflict offers Resolve and Undo, and Undo leaves everything else as it was.
- **New Worktree… from the sidebar.** A repository's row makes a worktree from that row's worktree, with the popover opening at the row. Branch › New Worktree… (Shift-Option-Command-B) does the same for the selected row.
- **Popovers open where they were asked for.** Branch here…, Worktree here…, Tag here… and New branch from stash… open at the row whose menu asked, in history and in the refs panel.
- **One switch for agents.** Settings › Agents starts with Use agents, which turns Generate, Resolve, Fix and the sidebar's marks on or off together. Under it, Default agent picks the agent that Generate, Resolve and Fix all run.
- **Custom agents.** Add Custom Agent… takes a name and a command, such as `ollama run qwen2.5-coder:7b`. Roga sends the task on standard input and takes what the command prints as the answer.
- **One agent popover.** Generate, Resolve and Fix each have a chevron that opens the same popover, where each agent is a card with its model and effort. A card's ⋯ menu changes them, and picking a card makes it the default. When an agent couldn't answer a Fix, Try Again has the chevron too, so another agent or a bigger model is a click away.

## Smaller changes

- Settings has General and Appearance, Git, and Agents. Commit messages and Large repositories are now sections of Git, and the Commit and Advanced pages are gone.
- Claude Code's and Codex's pages in Settings have the copy, the model, the effort and Run Test. The time limit is fixed at 60 seconds for a message and at least 3 minutes to resolve or fix.
- Settings and setup show the sidebar's marks as a piece of the sidebar, with a line out from each mark to what it means.
- Stash rows name their branch on the second line, as in `stash@{0} · main · 2 hours ago`.
- Headers no longer show counts. How many there are is in the header's tooltip.
- A repository's row drops its + button, since New Worktree… is in its menus.
- The refs panel's button stays in the window's top right corner whether the panel shows or not.
- The refs panel's Sort button is gone. Its ⋯ menu has Sort by, Filter refs, Collapse and Expand all sections, and Hide refs.
- A thin line separates Fetch and New Branch from the number of commits and the Order menu.
- The uncommitted row's words are gray, like a commit's author and date. Conflicts stay red.
- The repository's menu in the title row only switches worktrees.
- Messages say what happened without naming Roga as the one who did it.
- In a menu row that's too long, only the branch names are shortened, in their middle, and the words around them stay whole.
