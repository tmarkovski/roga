The seventh update to Roga, which marks an agent at work with the house's windows, says how far a branch is from main, renames branches, puts every branch in the refs panel on one line, and deletes several branches at once.

## What's new

- **The house's windows for an agent at work.** Wherever a turning ring used to mark an agent at work, the four windows of Roga's house now play: in the sidebar's rows, on the worktree tabs, in the branch row's popover, on the commit box's Stop button, above a conflicted file, and in Settings. There are six animations, and each launch of Roga picks one that the last launch didn't show. They stop while the window is hidden, and stand still under Reduce Motion.
- **How far the branch is from main.** In the row under the tabs, the branch's name has a second line, such as `4 ahead, 12 behind origin/main`. It counts against the remote's main branch, which doesn't go stale the way a local `main` does unless someone pulls it. It turns orange only when merging main would conflict, as in `15 behind origin/main · 2 files would conflict`. The agent gets two lines there too, with who and for how long over what it's doing, and the light runs through what it's doing instead of a ring turning beside it.
- **A popover for the branch.** Clicking the branch's chip opens a popover about the checkout instead of a menu. It has the folder, with Show in Finder, Open in Terminal and Copy Path, the upstream, and how far the branch is from main, with Rebase and Merge while main has commits the branch doesn't. Switch Branch… and Rename Branch… are at its foot. Pull, Push, Fetch and New Branch left it, since they're on the row and in the Branch menu.
- **Rename a branch.** Rename Branch… is in that popover and in the Branch menu, and a local branch's menu in history and the refs panel has Rename…. It renames the branch on this Mac only. The branch keeps tracking its upstream under the old name, so ↑ pushes to that name, as in `git push origin fix-login:agent/fix`, and a pull request on the old name keeps getting the commits. Afterwards the title row offers to rename it back.
- **Every branch on one line.** In the refs panel, local and remote branches take one line each. The icon says whose a branch is: green for the one checked out here, sky for the rest of yours, and the tab's icon for a branch another worktree has. After the name come gray counts, or `merged` for a branch whose commits are all in main, and the rest, such as how far it is from main and when it last changed, is in its tooltip. A button on the Branches heading deletes the merged branches that no worktree has.
- **What goes with a branch lights up.** Resting the pointer on a branch tints its upstream, or the branches that track it, and puts a ring on the tab of the worktree that has it. Pointing at a tab tints its branch. When the tinted row is out of view, a pill at the top or bottom of the list names it.
- **Delete several branches at once.** Right-click a folder of local branches for Delete 4 branches…, or pick branches with Command-click and Shift-click and right-click one of them. The dialog has a switch for each branch and says how many commits only that branch has. It keeps the branches that are checked out, and the main branch.
- **Locked worktrees.** A locked worktree's row in the sidebar has a gray lock, and its tooltip gives the lock's reason, such as the Claude Code session that holds it. Deleting one asks first and offers a red Delete Anyway, which forces git past the lock, and its menu has Unlock for clearing a stale lock without deleting anything.
- **A signature's key.** The commit panel's Signature line has a chevron with a menu for the key that made the signature: Copy public key, Copy fingerprint or Copy key ID, and Add to GitHub…. The last one helps when GitHub calls a commit Unverified that git calls good, because GitHub only verifies a signature made with a key the account has as a signing key, which is a separate entry from the same key added for logging in.
- **Settings' fields and dropdowns.** Fields and dropdowns are gray boxes, with a ring in the accent color while you use them. A dropdown opens Roga's own list, which works like a menu: it opens as the mouse button goes down, and takes the arrow keys, typed letters, and a press, drag and release. What Roga found on the Mac, such as Git, the agents and the plugins, sits on one gray card.

## Smaller changes

- History's row for uncommitted changes no longer shimmers while an agent works, since the tab and the branch row already say so.
- History's number of commits moved into the order's menu.
- Every control in the branch row is 36 points tall, so the gray fill under the pointer matches from one end of the row to the other.
- In the refs panel, a branch's counts are gray, as on the tabs, and a remote branch's date moved to its tooltip.
- The agent line puts Codex's newer tools in words, such as "Looking at" and an image's name.
- Labels, tooltips and dialogs across the app are reworded in plainer language, above all where they say what renaming a branch, applying a stash, resetting to a commit or deleting a worktree will do.
- The program rows in Settings and setup no longer have an icon tile, and the button that picks which copy of a program Roga runs is a dropdown box.
